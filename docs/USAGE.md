# Working extraction commands

Run commands from the repository root. Python 3.12 was used here. The scanner and SQLite query/recipe tools use only the standard library. Asset tools require the pinned dependency environment.

```bash
python tools/scan_game.py --game-root . --output analysis
python tools/query_game.py recipes ItemIronFrames
python tools/query_game.py types SimpleFabricatorBase
python tools/query_game.py methods SetRecipeFromHash
python tools/query_game.py objects StructureAutolathe
# After prefab extraction:
python tools/query_game.py prefabs StructureAutolathe
```

The scanner produces file, assembly, asset, XML, recipe and example-mod JSON plus `stationeers.sqlite`. Counts include framework and third-party assemblies; Assembly-CSharp counts are reported separately in GAME_ANALYSIS.md. Generated databases and large extracts stay out of Git and can be regenerated from the private source files.

## UnityPy environment

```bash
python -m venv .venv
# Linux: .venv/bin/python; Windows: .venv/Scripts/python.exe
.venv/bin/python -m pip install -r tools/requirements-assets-lock.txt
.venv/bin/python tools/unity_assets.py verify
.venv/bin/python tools/extract_prefabs.py
.venv/bin/python tools/unity_assets.py export rocketstation_Data/sharedassets0.assets --type Texture2D --limit 1 --output analysis/texture-example
.venv/bin/python tools/unity_assets.py export rocketstation_Data/resources.assets --type MonoBehaviour --path-id 107170 --managed rocketstation_Data/Managed --output analysis/autolathe-example
```

Other export types are Sprite, Mesh and TextAsset. Use exact path IDs to cherry-pick objects. Defaults export one successful object; failed selected objects are reported and return a nonzero status. MonoBehaviour decoding may require TypeTreeGeneratorAPI and all dependency assemblies. API names follow the installed versions, not older README examples.

Reference: https://github.com/K0lb3/UnityPy#installation

## Recipe mod export

This example creates a separate override that changes iron frames' Iron field from 4 to 5. It is an example only; the tool does not install the mod or change the source game.

```bash
python tools/export_recipe_mod.py --source rocketstation_Data/StreamingAssets/Data/autolathe.xml --section AutolatheRecipes --prefab ItemIronFrames --set Iron=5 --output analysis/my-mod --name IronFramesExample
```

Install the exported mod folder under the game's local mods directory, following the included game example's `%userprofile%\documents\my games\stationeers\mods` guidance. Enable it and set the appropriate load order in game, then inspect the active recipe. No installation or runtime verification was performed here. Preview/thumbnail images are not generated by this exporter.
